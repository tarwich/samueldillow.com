# Project Instructions

Whenever writing or editing prose for this site, consult `tone.md` first and match its guidance.

This applies to page copy, blog/chapter text, headings, descriptions, excerpts, calls to action, and other reader-facing prose.

Always nest CSS when available. Remember this isn't SASS, so you can't do &__foo, but you CAN do simple nesting.

New articles must appear on the front page. Keep the homepage writing list ordered by publication date and include new visible English articles automatically, without requiring the `featured` flag. Verify homepage placement when publishing an article.
