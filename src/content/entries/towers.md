Towers is a small browser version of the Skyscrapers puzzle: each row and
column must contain each height once, and edge clues tell you how many towers
are visible from that side.

The game is intentionally small, but it is useful as a test bed for interaction
state, undo/redo behavior, shareable seeds, and responsive browser UI.
